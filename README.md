# Animal Sound Support Site

Static support/legal site for App Store Connect and Google Play, served via GitHub Pages.

Live URLs:

- Support: `https://yesilmenveysel.github.io/animalsound-support/support.html`
- Privacy Policy: `https://yesilmenveysel.github.io/animalsound-support/privacy.html`
- Terms of Use: `https://yesilmenveysel.github.io/animalsound-support/terms.html`

Replaces three separate, inconsistent Google Sites pages (`animalsoundidentifier`,
`animalsoundsidentifier`, `animal-sounds-identifier`) that publicly showed a personal
Gmail address and, in the privacy page, an outdated claim that the app does not collect
location data. Contact across this site is `info@appsfork.com`.

Required files: `index.html`, `support.html`, `privacy.html`, `terms.html`, `styles.css`.
